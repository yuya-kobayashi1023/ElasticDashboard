# Elastic Dashboard

CSV や Excel を読み込むと、列の種類を自動で判定してダッシュボードを作る Web アプリです。作ったダッシュボードは画面上で編集でき、1 つの HTML ファイルとして書き出せます。データはブラウザ内で処理・保存し、外部には送信しません。

計画と今後の予定は [docs/PLAN.md](docs/PLAN.md)、ユーザビリティ原則との対応は [docs/HEURISTICS.md](docs/HEURISTICS.md) にあります。

## 使い方

1. ファイルをドロップするか「ファイルを選択」で読み込みます（CSV・TSV・Excel・JSON、表の貼り付け、書き出した HTML）
2. 読み込んだ直後のダッシュボードにはウィジェットがありません。「ウィジェットを追加」で 1 つずつ追加するか、「自動で作成」でデータの内容に合わせてまとめて作ります。各ウィジェットの鉛筆アイコンから、種類・集計・列・幅・色を変えられます
3. 「列の設定」タブで、列の表示・非表示、表示名、種類、単位を変えたり、計算列を追加したり、別のファイル（マスタ）の列を結合したりできます
4. 「デザイン」で、背景・アクセント色・グラフの配色・余白・角の丸み・文字の大きさを変えられます
5. 次回のデータは「データを更新」から、差し替えるか行を追加します。レイアウトと列の設定はそのまま使えます
6. 「HTML を書き出し」で、単体で開けるファイルを保存します。テンプレート（データなし）を選ぶと、開いたあとで同じ形式のファイルを読み込んで使えます

## 開発

ランタイムは mise で管理し、パッケージ管理には Bun を使います。

```bash
bun install
bun run dev        # 書き出し用ビューアをビルドしてから開発サーバーを起動
bun run test       # 単体テスト（vitest）
bun run typecheck  # 型チェック
bun run build      # 本番ビルド（dist/）
bun run samples    # サンプルデータを作り直す（samples/）
```

`samples/` に、動作確認用のサンプルデータ（売上・問い合わせ・経費精算を 3 か月分ずつ）があります。内容と試し方は [samples/README.md](samples/README.md) を参照してください。

`src/generated/` には、書き出し用ビューアのビルド結果が入ります。`dev` と `build` の前に自動で作られます。

Excel の読み込みに使う SheetJS は、公式 CDN（`cdn.sheetjs.com`）から 0.20.3 を入れています。npm に公開されているバージョンは更新が止まっているためです。
