# ユーザビリティ原則との対応

ニールセンの 10 のユーザビリティ原則ごとに、設計で対応した内容をまとめています。ヒューリスティック評価で確認する箇所の目安として使えます。

| 原則 | 対応している内容 | 確認する画面 |
|---|---|---|
| 1. システム状態の可視化 | 読み込み中の表示、大きなデータの集計中の表示、保存状態（保存中・保存済み・保存できませんでした）、フィルタ適用後の行数（「391 / 1,200 行」）、絞り込み中のフィルタと選択中の棒の強調 | ヘッダー、フィルタバー |
| 2. 実世界との一致 | 業務で使う語（件数・合計・ユニーク数・四半期）、和暦や △ 表記の負数、¥・円・% の単位の引き継ぎ、万・億の単位でのグラフ目盛り | グラフ、列の設定 |
| 3. ユーザーの制御と自由 | すべての編集の取り消しとやり直し（Ctrl+Z / Ctrl+Shift+Z）、データの差し替えと行の追加も取り消せる、削除後の通知から「元に戻す」、自動判定への復帰ボタン、デザインを既定に戻すボタン | ヘッダー、通知、デザイン |
| 4. 一貫性と標準 | ボタン・入力欄・カードの寸法と色を共通の値で定義、同じ概念に同じアイコン（数値は # など）、ダイアログは標準の `<dialog>` を使用 | 全画面 |
| 5. エラーの防止 | 列がほとんど一致しないデータへの差し替え前の確認、取り消せないダッシュボード削除の確認、集計方法に合う列だけを選択肢に表示、書き出しに含めない列を事前に表示、行の追加で重複した行を通知、カスタム配色で見分けにくい色と背景に埋もれる色を警告、計算列の同名チェックと計算結果のプレビュー、マスタ結合前の一致件数と一致しない値の表示 | 差し替え、削除、編集パネル、デザイン、計算列 |
| 6. 記憶より認識 | 列の選択肢に種類を併記（「売上金額（数値）」）、フィルタの値に件数を表示、タイトルの空欄時に自動タイトルを入力欄の例として表示、列の設定に値の例を表示 | 編集パネル、フィルタ |
| 7. 柔軟性と効率 | ファイルを画面のどこにでもドロップ、棒グラフのクリックで絞り込み、キーボードでの並べ替え、データ差し替えで設定を再利用、レイアウトの再生成、テンプレート HTML でアプリなしに毎月の資料を作成 | ダッシュボード、書き出した HTML |
| 8. 美的で最小限のデザイン | 説明文を置かず、短い見出しと操作の配置で伝える。色はグラフと主要な操作に限定し、カードの入れ子を避ける | 全画面 |
| 9. エラーの認識・診断・回復 | 読み込みエラーの原因と対処（「パスワード付きか、破損している可能性があります」）、表示できないウィジェットに理由と「設定を開く」ボタン、変換できない値の件数、計算式の誤りの位置と内容（「[」に対応する「]」がありません など） | 取り込み、ウィジェット、計算列 |
| 10. ヘルプとドキュメント | 取り込み時の補正内容（除外した行、文字コード）を通知、編集パネルで必要な箇所にだけ補足を表示、時系列グラフにキーボード操作の説明（読み上げ用） | 通知、編集パネル |

## アクセシビリティ

- すべての操作をキーボードで行えます。棒グラフの棒は Tab で選び Enter で絞り込み、時系列グラフは左右の矢印キーで値を確認できます
- アイコンだけのボタンには読み上げ用の名前を付けています
- グラフの系列は、色だけでなく凡例と直接ラベルでも区別できます。既定の配色は、明るい背景と暗い背景のそれぞれで、色覚の違いを考慮した検証スクリプトに通しています
- KPI の増減は、色だけでなく矢印と符号付きの数値でも示します
- 散布図の点は、分類ごとに形（○ □ ◇ △）も変えます
- 「デザイン」で模様の塗り分けをオンにすると、複数系列の縦棒は斜線の模様、折れ線は線の種類でも区別できます。印刷時と強制カラーモードでは常に模様を付けます
- クロス集計の濃淡は補助の表示で、各セルには値を文字で表示します
- 幅の狭いカードでは、編集用のアイコンを 1 つのメニューにまとめ、タイトルの幅を確保します
- 動きを減らす設定（`prefers-reduced-motion`）では、アニメーションを止めます
