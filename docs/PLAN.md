# プロダクト計画

## 解決したい課題

業務で使うプロダクトごとに、専用のダッシュボードを毎回作るのは手間がかかります。データの形式はプロダクトごとに違い、列名も単位も文字コードもそろっていません。

このアプリでは、CSV や Excel を読み込むだけで、列の種類を自動で判定してダッシュボードを作ります。作ったあとで、表示する列、グラフの種類、集計方法、並び順を画面上で変えられます。できあがったダッシュボードは、1 つの HTML ファイルとして書き出して共有できます。

## 想定する利用者と場面

- 自社や取引先のプロダクトから、CSV や Excel を定期的に出力している担当者
- BI ツールを導入するほどではないが、数字の推移や内訳をすぐに確認したい人
- 集計結果を、ツールを持っていない相手にファイルで渡したい人

代表的な流れは次のとおりです。

1. 管理画面から書き出した CSV をブラウザにドロップする
2. 表示したいグラフを「ウィジェットを追加」で選ぶか、「自動で作成」でまとめて作り、不要な列を隠したり、グラフの集計を変えたりする
3. 翌月は同じダッシュボードに新しい CSV を「データを差し替え」で読み込む。レイアウトと列の設定はそのまま使える
4. 会議の前に HTML を書き出し、関係者に送る

## 製品の方針

- 読み込み時には質問しない。列の種類の判定と期間・カテゴリのフィルタは自動で用意し、ウィジェットは利用者が選ぶ（まとめて自動で作ることもできる）
- 自動判定の結果は、すべて画面上で確認・変更できるようにする
- データは外部に送信しない。処理と保存はブラウザ内で完結させる
- 一度作った設定を、次のデータでも使い回せるようにする（2 回目以降の手間を減らす）
- 書き出した HTML は、ネットワークにつながっていない環境でも開けるようにする

## 機能の範囲

### 実装済み

| 領域 | 内容 |
|---|---|
| 読み込み | CSV・TSV・Excel（xlsx / xls / ods）・JSON、表の貼り付け、サンプルデータ、書き出した HTML（ダッシュボードとして復元） |
| 読み込みの補正 | Shift_JIS の自動判定、タイトル行と末尾の合計行の除外、見出しがないときの列名の自動付与、重複した列名の区別、複数シートの選択 |
| 型の推定 | 数値（¥・%・円・カンマ・△ や括弧の負数）、日付（西暦、和暦、`20250105` 形式、年だけの列）、時刻、時間の長さ、真偽値、カテゴリ、テキスト、ID 風の列。`NA`・`N/A`・`NaN` などは空欄として扱う。見出し行がないファイルも判定する。時刻・時間の長さ・真偽値・Unix 秒 / ミリ秒の日時は、確実なときだけ判定する。「日/月/年」と「月/日/年」の順序も、判別できる値があるときだけ決める。判定した理由は列の設定に表示する |
| 自動作成 | 読み込み時はウィジェットを作らず、期間とカテゴリのフィルタだけを用意する。「自動で作成」を押すと、KPI（4 枚）、推移、カテゴリ別の棒グラフ、分布、データ一覧を作る |
| ウィジェット | 数値（KPI）、棒グラフ、推移、分布、散布図、クロス集計、表、ドーナツ、ヒートマップ、メモ、ゲージ。推移は、分類の列で系列に分けるほか、複数の数値列（都道府県ごとの列など）を並べられる |
| KPI の比較 | 最新の期間（日・週・月・四半期・年）の値、前の期間からの増減率、直近 12 期間のスパークライン、期間の途中であることの表示 |
| 編集 | ウィジェットの追加・複製・削除・並べ替え（ドラッグとキーボード）、種類・集計・列・幅・色の変更 |
| 列の設定 | 表示・非表示、表示名、種類の変更と自動判定への復帰、単位と小数桁、変換できない値の件数 |
| 列ごとの解釈 | 値をどう読むかを列ごとに設定し、結果をその場でプレビューする。日付は書式（年月日の順序やパターン）、時刻は書式、時間の長さは単位と「12:34」の意味（時:分か分:秒か）、真偽値は「はい」「いいえ」とみなす語、数値は小数点のカンマと倍率、テキストは表記の正規化を選べる |
| 計算列 | 数値の列を使った四則演算（`[売上金額] / [数量]` など）、日付からの年・四半期・月・年月・曜日・日・時の取り出し、年・月・日などに分かれた列からの日付の組み立て。曜日と月は暦の順に並ぶ |
| マスタの結合 | 別のファイルの列を、共通の列をキーにして追加する（担当者 → チーム など）。複数の列を組み合わせたキー（担当者 + 年月 など）も使える。日付のキーは書き方が違っても同じ日なら一致する。結合したマスタは、あとから新しいファイルに差し替えたり、結合を解除したりできる。キーの表記の揺れ（「001」と「1」、全角数字）は同じ値として扱い、結合前に一致件数と一致しない値の例を表示する。マスタは設定と一緒に保存されるため、データを差し替えても結合は残る |
| デザイン | 数値の表記（k / M、万 / 億、省略しない）、背景（ウォーム・ホワイト・ダーク）、アクセント色、グラフの配色（検証済みの 2 種類とカスタム）、余白、角の丸み、文字の大きさ。カスタム配色は見分けにくい組み合わせを警告する。複数系列のグラフを模様と線の種類でも塗り分ける設定（印刷時は常に有効）。グラフの軸には、列の単位を含む軸タイトルを表示する |
| 絞り込み | フィルタバー、棒グラフのクリックによる絞り込み、データの最終日を基準にした期間のプリセット（データを更新しても最終日から数え直す）。日時の列は、時刻まで指定して絞り込める。「直近 24 時間」のプリセットもある |
| 時間の集計 | 日付・時刻の列を、年から日に加えて時・分・秒の単位でも集計できる。時刻だけの列は、時刻の軸（0 時から 24 時）でグラフにできる。点が多すぎて単位を粗くしたときは、そのことをグラフに表示する |
| 表ウィジェット | 列ごとのフィルタ行、並べ替え、列の順序の変更、「すべて表示」「すべて外す」、行番号、セルの折り返しを設定できる |
| ウィジェットの設定 | 「基本」「データ」「表示」「数値の書式」の 4 つの区分にまとめて表示する。主な項目は、ウィジェットごとの数値の書式、KPI の目標値、棒グラフの向き・値の表示・「その他」への集約、累積、移動平均、分布の階級数、散布図の近似直線、クロス集計のヒートマップ表示と表示件数の上限、サブタイトル |
| 保存 | IndexedDB への自動保存、複数ダッシュボードの切り替え、元に戻す・やり直す |
| データの更新 | 差し替え（列名で対応付け、列が大きく異なるときは確認）、行の追加（同じ内容の行があれば通知）、どちらも取り消せる。列の種類は新しいデータでも変換できる限り保ち、変わった場合は通知する |
| 書き出し | 単体で動く HTML。データを含める形式と、設定だけのテンプレート形式を選べる。ビューアとデータは gzip で圧縮して埋め込む（約 860 行のデータで約 350 KB） |
| 書き出した HTML | フィルタ・並べ替え・ツールチップが動く。同じ形式のファイルを読み込み直し、そのデータで HTML を保存し直せる。結合したマスタも新しいファイルに差し替えられる。アプリに読み込むと編集できるダッシュボードに戻る |

### 書き出した HTML の使い回し

書き出した HTML は、閲覧用の資料であると同時に、同じ形式のデータを読み込むためのツールとして使えます。

1. アプリでダッシュボードを作り、「テンプレート（データなし）」で書き出す
2. 翌月、テンプレートの HTML をブラウザで開き、新しい CSV をドロップする
3. 「HTML を保存」で、そのデータを含む HTML を保存して共有する
4. レイアウトを直したくなったら、その HTML をアプリの「新規作成」画面に読み込む

アプリを使わない人も、手順 2 と 3 だけで毎月の資料を作れます。

### 大きなデータでの動作

30 万行（約 27 MB）の CSV で測った値です。

| 項目 | 値 |
|---|---|
| ファイルを選んでから表示まで | 約 1.2 秒 |
| 画面が操作できない時間（最長） | 約 0.23 秒 |
| フィルタを変えたときの再集計 | 約 40 ms |

ファイルの解析と列の種類の推定は Web Worker で行います。グラフ用の集計データは、5 万行以上のときは画面側で少しずつ作り、その間も操作できます。行のデータは JSON 文字列として受け渡し・保存し、大きな配列の複製で画面が止まらないようにしています。

### 次に取り組む候補

1. 読み込み時の残りの停止（約 0.23 秒）の解消: 行のデータを列ごとの形で受け渡し・保存すれば、JSON の変換もなくせる

公開データで確認して見つかった改善点は [TASKS.md](TASKS.md) にまとめています。

## 構成

- React + TypeScript + Vite で作った、サーバーを持たない Web アプリです
- グラフは SVG で自作しています。外部のグラフライブラリに依存しないため、書き出した HTML にもそのまま組み込めます
- 書き出し用のビューア（`src/viewer`）を別にビルドし、HTML にインラインで埋め込みます。ビューアにはファイルの解析処理も含まれるため、書き出した HTML の中だけでデータを読み込み直せます
- ファイルの解析は Web Worker で行い、読み込み中も画面が固まらないようにしています

主なディレクトリは次のとおりです。

| パス | 役割 |
|---|---|
| `src/core` | 解析、型推定、集計、自動レイアウト、書き出し。UI に依存しない |
| `src/components` | アプリとビューアで共有する部品（グラフ、フィルタ、表） |
| `src/app` | アプリ固有の画面と状態管理 |
| `src/viewer` | 書き出した HTML で動くビューア（閲覧、データの読み込み直し、HTML の保存し直し） |

## 既知の制約

- データはブラウザごとに保存されます。別の PC やブラウザとは共有されません
- ブラウザのサイト データを消去すると、保存したダッシュボードも消えます
- 書き出した HTML にはデータそのものが含まれます。共有先には注意が必要です
- 年・月だけの日付は月初、時刻つきの日付はタイムゾーンを無視した表示時刻として扱います
- 一度に読み込むのは 1 ファイル（Excel は 1 シート）です。複数のファイルは「行を追加する」で順につなげます
- 書き出した HTML の中で読み込み直したデータは、「HTML を保存」を押すまでファイルに残りません
